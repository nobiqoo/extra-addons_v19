HR_ZK_ATTENDANCE
================
Este módulo establece la conexión entre el módulo de Asistencias de Odoo (v19) y los dispositivos biométricos ZKteco. Sincroniza automáticamente las marcaciones del personal, registrando la primera marcación del día como **Entrada** y la última como **Salida** para el control preciso de la asistencia.

Configuración
=============
* Este módulo requiere la instalación de la librería Python 'zklib'.
* Puedes instalar la librería usando: ``sudo pip install zklib``

Compatibilidad de Dispositivos (ZKteco)
---------------------------------------
Este módulo está diseñado para integrarse con dispositivos de asistencia biométrica de ZKteco.
Modelos Típicamente Compatibles:
* ZKteco Speedface V4 y V5
* ZKteco Horus Tl2
